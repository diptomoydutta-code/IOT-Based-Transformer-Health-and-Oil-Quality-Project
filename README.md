# IOT-Based Transformer Health and Oil Quality Project
ESP32 transformer-oil monitor:   reads temperature, turbidity, voltage, and current sensors, then   reports values to Blynk and activates the LED and buzzer on faults.





Contributors :- Anick kundu , Sagnik chattaraj , Diptomoy Dutta , Ayan dutta  and  Souvik Ghosh 






The loT-Based Transformer Health & Oil Quality Monitor is a real-time condition monitoring system designed to detect early signs of transformer failure caused by overheating, overloading, and oil degradation.

By combining sensor data, edge processing, loT connectivity, and remote alerts, this system transforms traditional periodic inspection into continuous, data-driven monitoring improving grid reliability, reducing downtime, and enhancing operational safety


Problem Statement

"Transformer faults caused by overheating, overloading, and oil degradation are often detected too late, leading to downtime, high costs, and safety risks."

Core Issues

Silent failures: Faults build up gradually and go unnoticed between inspections.

Manual inspection limits: Periodic checks cannot provide continuous real-time monitoring.

High consequences: Unexpected outages, expensive replacements, and safety hazards.
 Who Is Affected

Utility operators Maintenance teams Grid managers Communities dependent on reliable power distribution.

+)

Proposed Solution

A continuous loT monitoring system that:

Collects real-time transformer condition data via sensors

Processes data at the edge using ESP32-S3

Transmits metrics securely to the cloud via Wi-Fi

Displays live trends on a web/mobile dashboard

Triggers threshold-based alerts remotely
 Think of it as giving the transformer a live health monitor that never sleeps.
